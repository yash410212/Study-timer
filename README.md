# Moss & Moon — Forest Study Timer

A lightweight offline-first Android WebView app with a forest theme, focus/break timer, tasks, and generated bird/chime sounds.

## Build APK on GitHub (free)
1. Open **Actions** → **Build Moss & Moon APK**.
2. Choose **Run workflow** if it has not started automatically.
3. Open the successful workflow run and download the `moss-moon-debug-apk` artifact.
4. Extract the ZIP to get `app-debug.apk`, then install it on your Android phone.

This is a debug APK for personal testing. Test thoroughly before distributing it; a signed release build is recommended for broader distribution.
